# tr3x

T3 Code's orchestration v2 in Rex: every thread is a Rex tab, and you can switch models and providers mid-thread.

It's an early work in progress. The design is `docs/tr3x-design.md` (PR #24). This repository currently carries upstream T3 Code; the tr3x package is next.
